# **App Name**: FleetOps

## Core Features:

- Secure User Authentication: Enable secure login for both web administrators/dispatchers and mobile drivers with email/password. Includes a 'Remember me' option for convenience.
- FleetOps Web Dashboard: A centralized web dashboard providing a quick overview of fleet and trip statuses, real-time map view of active trucks, and critical alerts regarding licenses or delayed trips.
- Fleet Resource Management (Web): Comprehensive tools for managing trucks (registration, status, capacity), drivers (profiles, license expiry alerts), transport companies, and client information, including merchandise details.
- End-to-End Trip Management (Web): Functionality to create, assign, and track logistics trips from origin to destination. Includes features for assigning drivers/trucks, managing trip statuses, and closing trips with arrival confirmations and document uploads.
- AI-Powered Trip Assignment Tool: An intelligent tool that assists dispatchers in assigning the most suitable trucks and drivers to new trips by considering real-time availability, vehicle capacity, driver qualifications, and proximity, to optimize dispatching efficiency.
- Driver Mobile App - Active Trip Management: A dedicated mobile interface for drivers to view their current trip details, update trip statuses (e.g., 'Iniciar viaje', 'Llegué al destino'), share their real-time location, and upload photos for delivery confirmation.
- Driver Mobile App - Trip History: Provides drivers with access to a detailed log of their past completed trips, including relevant information such as destination and final status for historical review.

## Style Guidelines:

- Primary brand color: Dark, almost black (#0C0E0B) representing professionalism and strength.
- Background color: A light, serene blue-gray (#D6E7F3), providing a clean and modern canvas.
- Accent color: A striking red (#D6303A) to highlight calls to action, alerts, and critical information, ensuring clear visual emphasis.
- Headline and body text font: 'Inter', a clean sans-serif typeface that offers excellent readability and a modern, objective aesthetic for all application text.
- Use clear and modern icons relevant to transportation, logistics, and management tasks, maintaining a consistent visual style across both web and mobile platforms.
- Web panel layout: A fixed sidebar for primary navigation with descriptive icons and labels. Mobile app layout: Intuitive bottom navigation for easy access to main driver functionalities.
- Subtle and functional animations to indicate state changes, such as loading data or status updates, improving user feedback without distraction.
